<parameter name="content"># tradebdy

### Your personal algo trading research desk.

Write strategies. Backtest them. Paper trade live. All on your machine — no subscriptions, no cloud, no data leaving your device.

---

## Built for traders who think in code — and those who don't

Whether you want to write Python or just describe what you want, tradebdy gets you from idea to live paper trade faster than anything else.

---

## Features

### 📓 Smart Notebook
A Python notebook with an **AI co-author built in**. Type what you want to analyse — *"show me when volume spikes above the 20-day average"* — and the AI writes and runs the code. Full pandas, numpy, and technical indicators available out of the box.

### 📊 Backtest Engine
Test any strategy on real historical data from your broker. Every backtest gives you:
- Total return and alpha vs benchmark
- Sharpe ratio and max drawdown
- Win rate and profit factor
- Full trade-by-trade breakdown
- Interactive equity curve

### 🤖 Strategy Studio *(no coding needed)*
Describe your strategy in plain English. The AI writes the code, validates it, backtests it, and draws a visual logic diagram — all automatically. Tweak the parameters and re-run with one click.

### 📈 Paper Trading
Run your strategies live against real market prices with a virtual portfolio. See mark-to-market P&L update in real time. Multiple algos running in parallel, each with its own stop loss and take profit. Circuit breaker to pause everything if drawdown hits your limit.

### 👁 Watchlist
Track any equity with live prices, change, open/high/low/close, and volume — all updating live from your broker.

## Your data, your machine

- No accounts required
- No telemetry or analytics
- No data stored in the cloud
- Credentials stored locally with restricted file permissions
- Uninstall anytime — your data stays in your home folder

## Install

**Linux**
```bash
sudo dpkg -i tradebdy_0.1.0_amd64.deb
```

**macOS** — open the `.dmg`, drag to Applications.
First launch: System Settings → Privacy & Security → Open Anyway.

**Windows** — run the `.exe` installer.
SmartScreen warning: More info → Run anyway.
